# Federated Ads Protocol link relations

## node

`https://w3id.org/federated-ads/rel/node`

Used in a WebFinger (RFC 7033) response to point from a domain or account to that domain's Federated Ads Node Descriptor. The link target is the Node Descriptor URL, and its media type is `application/federated-ads+json`.

Defined in the Internet-Draft [`draft-rajan-federated-ads-protocol-00`](../ietf/draft-rajan-federated-ads-protocol-00.html), section "Identity, Keys and Discovery".
