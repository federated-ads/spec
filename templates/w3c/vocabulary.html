This document defines the vocabulary, JSON-LD context, JSON Schemas and registries used by the Federated Ads Protocol. The wire protocol itself is specified in [[FEDERATED-ADS-PROTOCOL]].

This is an unofficial draft prepared for a proposed W3C Community Group. It has no standing at W3C.

Introduction

Federated Ads Protocol objects are plain JSON. Verifiers work on the JSON bytes, so JSON-LD processing is optional. The vocabulary exists so the objects can also be read as linked data.

Namespace and context

The namespace is https://w3id.org/federated-ads/v0#, with the prefix fa:. The JSON-LD context is published at https://w3id.org/federated-ads/v0.
